# 第64章 冷战

高二的春刚上来，路两边的樟树开始落叶，我和江苒开始冷战。

起因小得可笑。午休时她在帮顾远抄落下的课业笔记，字写得很认真，我路过看了一眼，嘴上没把门，说了句你倒是对谁都上心。她笔尖停了一下，没抬头，只说你要是累了就先去睡。我听着那语气，心里一堵，回了句我不困，你忙吧，然后转身就走。

那天下午风很凉，带着食堂飘来的饭菜气息。我坐在座位上，后背贴着冰凉的椅背，耳边全是粉笔划过黑板的沙沙声。江苒隔着过道翻书，声音很轻，却落在我心上。

放学时我故意磨蹭，等她先走。她果然没等我，和林小满一起出了教室。门口的光落在她发梢上，把影子拉得很长。我看着那个背影，脚动了一下，又收了回来。

我把桌上的书一本本摞齐，书角对齐桌角，粉笔灰蹭到手指，干干涩涩的。我拿出抹布把桌面擦一遍，布是半湿的，擦过的地方颜色深一块，凉气透上来。我把抹布拧干，水滴落在盆里轻响。窗外食堂的烟气飘进来，混着潮雾的腥气，我深吸一口气，又慢慢吐出去。

第一天晚上，我翻来覆去睡不着。空气里有洗衣粉的淡香，还有窗外飘进来的湿雾气。我摸出枕头底下的旧磁带，塑料壳硌着掌心，最后只是攥在手里，攥出了汗。

陈默在上铺翻身，小声说，沈聿你转来转去，床都要晃散了。我说吵到你了，他说没有，就是听着难受。我把磁带放回去，又摸出来，指腹在齿轮上轻轻拨一下，听见很轻的咔声，心里反而更空。

第二天早上雾很大，整个县城像是泡在牛奶里。我到教室时江苒已经到了，正在擦桌子。桌角放着一小罐海盐糖，是宋阿婆托人带来的。我看见罐子往我这边移了半寸，又停住，又推了回去。

“早。”林小满跟我打招呼，声音压得很低，还朝江苒那边使眼色。

“早。”我说，嗓子有点哑。

一上午我们没说一句话。老师在上面讲课，我盯着书本，字看不进去，只闻到陈默身上淡淡的汗味和墨水味。他拿胳膊肘捅我，递来一张小纸条，上面写着，晚上操场说。

我说好。

中午吃饭，江苒和何晓坐一桌，我和陈默坐另一桌，明明只隔两张桌子，却像隔了一条河。我低头扒饭，米饭有点硬，咽下去时喉咙发紧。

“你俩到底怎么了？”陈默拿筷子敲我的碗，“就为那点笔记的事？”

“没怎么。”我说。

“没怎么会两天没说话？”他瞪我，“你就是嘴欠，人家帮同学抄个笔记，你酸什么。”

“我没酸。”

“你还没酸，脸都快掉进醋坛子了。”陈默压低声音，“江苒是什么人你不知道？她对谁都客气，可对你不一样。她给过别人纸星星吗？就你有。”

我不说话，用筷子戳着碗里的菜。

“能不能主动点？”陈默恨铁不成钢，“女生是要哄的，你冷着她，她更冷，你俩比赛冻死谁啊。”

“我不知道怎么开口。”我说的是实话，每次看到她平静的侧脸，准备好的话就全散了。

“出息。”陈默骂了一句，又塞了一大口饭，含糊不清地说，“晚上我帮你制造机会，你自己争气点。”

下午的课很漫长。我偷看江苒，她正低头折纸星星，手指翻飞。她说过，难过时就折星星，把不高兴的事折进去，心里会好受些。

下课铃响时，她把那颗星星放进抽屉，没有给我，我的心像是被捏了一下。

晚上我按约去了操场。草地有露水，风带着青草和泥土的凉意。陈默已经在等我，双手插兜，来回踱步。

“来了？想好怎么和好了没？”

“没想好。”

“你啊。”陈默指着我，气得转圈，“人家给你带糖，给你折星星，陪你去看宋阿婆，你就为这点小事置气？这都第二天了，明天第三天，你还想凑个整？”

“我气的不是你。我怕她对谁都那么好，那我算什么呢。”

“你是沈聿啊。”陈默说，“她对别人好是礼貌，对你好是用心，这都分不清？平时挺聪明，一到她这就犯糊涂。”

他的声音在空旷的操场显得格外响，惊起角落一只夜鸟，扑棱棱飞远了。

“我错了。”我说。

“知道错还不去认？”

“我拉不下脸。”

“脸重要还是人重要？”陈默骂道，“你要脸，就等着后悔吧。我告诉你，顾远再好，也没你跟她认识久，你再冷下去，小心她真寒心了。”

我低头看着脚尖的露水，心里乱成一团。

正说着，何晓从跑道那头走来，手里拿着两瓶热水，递给我们一人一瓶。瓶身暖暖的，握在手里很舒服。

“你们在这儿开批斗会呢？”她笑着说，眼睛亮亮的。

“批他呢，油盐不进。”陈默说。

何晓看我一眼，语气软下来：“沈聿，你别怪他说话冲，他是为你急。其实江苒这两天也不好受。”

“她怎么了？”我立刻抬头。

“想你呗，又不好意思先开口。”何晓说，“今天中午她跟我说，折星星时满脑子都是你那句话。她说帮顾远抄笔记是因为之前欠了人情，不得不帮。她还说，你要是再不理她，她就把给你的那罐星星全送人了。”

“别送人。”我急了。

“那你去说啊。”何晓把热水往我手里塞了塞，“她看着温和，心里敏感得很，你一句话，她能想半天。你倒好，一冷就是两天，明天就是第三天，真打算创个纪录？”

我捧着热水瓶，热气烘得下巴发潮。我想起那天在走廊，她帮顾远抄笔记时发顶的光，还有她说你要是累了就先去睡时的语气。心里像有根细线被轻轻扯了一下，又酸又紧。我低声说，我这回真的怕了，怕一开口又说错。

“我明天去找她。”我说。

“怎么找？直接说对不起？”陈默问。

“嗯，还有把磁带借她听，里面有我们一起录的歌，她心情不好时听，会好一点。”

“这还差不多。”何晓点头，“态度软点，别端着了，你先低头，又不会少块肉。”

“还有海盐糖别忘。”她提醒，“她喜欢咸咸甜甜的味，你给她剥一颗，比说什么都管用。”

陈默补充：“她要还不理你，你就站那儿别走，站到她心软为止，听见没？”

“听见了。”我笑了，还是紧张。

夜风渐大。我们站在操场中央，谁也没再说话。远处教室亮着几盏灯，暖黄的光落在雾气里。我抬头看天，云很厚，看不见星星。

回宿舍路上，何晓说：“江苒问我，你是不是还在生气。我说你哪里生气，明明是想她想得睡不着。”

“我哪有。”我嘴硬，耳朵却热起来。

“行了，别装了。”陈默搭着我的肩，“明天好好表现，不然我和何晓都不帮你了。”

我点头，心跳有点快。口袋里的海盐糖硌着腿，是何晓塞的，她说这是江苒分给她的，让我借花献佛。

熄灯后我躺在床上，闻着被子上阳光晒过的味道，翻来覆去都是明天的事。我在脑子里排练好多遍，先说什么，再说什么。

迷迷糊糊快睡着时，听见陈默在上铺翻身，嘟囔一句：“傻子，快和好吧，看得我都累了。”

我闭着眼，在心里回，好，明天就和好。

第三天清晨，我比平时早起半小时。雾还没散，空气凉得沁人。我把旧磁带擦干净包好，又数了几颗海盐糖装进口袋。糖纸在指尖发出细微脆响，甜香混着咸香飘出来。

我把磁带包进绒布，再放进纸袋，袋口折三次压平。热水倒进杯子，热气在冬晨里散得很快，我喝了一口，舌尖有点烫，心跳也快起来。走廊里拖把划过地面的声音很轻，我抱紧纸袋往教室走，脚步落在薄雾里，鞋底有点潮。

我到教室时里面没人，把磁带轻轻放在江苒桌上，又放了一颗剥好的糖，糖放在纸星星旁边，颜色很亮。

然后我坐回位置，等她来，等雾散，等第一缕阳光落进来。

门外传来脚步声，很轻，一下，又一下，停在了门口。
