# 第三卷 潮汐 · 第72章 卷末

高二的尾巴是被雨泡软的。

早上进教室的时候，走廊的地面还汪着一层薄水，鞋底踩上去发出很轻的吱声。风扇在头顶转着，带着一股铁锈和粉笔灰混在一起的气味。窗外雾山市上空的云压得很低，南雾县这几日一直潮，墙角都洇出了深色的边。

我把书包塞进桌肚，指尖先碰到了那个玻璃罐。罐身凉凉的，被桌肚的木纹硌了一下。

罐子是江苒放在我这里的，春天时里面还很空，如今摇一摇，会发出细碎的碰撞声，像一罐被风摇晃的潮。她叠的纸星星一个个棱角分明，粉的黄的蓝的，挤在一起，像一罐没化开的潮汐。我把罐子捧在掌心转一圈，玻璃被手温慢慢焐热，星星的角透过玻璃硌着掌心，轻轻的痒。

林小满从后面拍我的肩，头发上还沾着雨气，发梢凉凉的蹭到我肩头。

“数过了吗，够数了吗。”她声音压得很低，眼睛亮亮的。

我摇头，把罐子推到桌角，怕碰倒，又用书本挡了一下。陈默正趴在前排补觉，校服袖子挽到手肘，露出晒出的分界线，呼吸轻轻的。顾远在黑板上抄假期安排，粉笔末落在他鼻尖上，灰灰的一点，何晓凑过去，用指尖帮他抹掉，指腹带过一点凉，两个人笑成一团，笑声在雨气里很轻。

教室里有种奇异的松。课本都收起来了，桌上堆着要带走的杂物。叶老师抱着一摞表格走进来，目光在我们脸上扫了一圈，忽然就不急着说话了。

“都坐好，最后一次点名。”她说。

点名的声音混着雨声，一个接一个。秦浩喊到，赵晴喊到，江苒喊到，我喊到。每一个到字落下，风扇就转过一圈，好像把这个夏天也翻过去一页。

散会后，大家都不急着走。教室的椅子轻晃，书本合上的声音此起彼伏。我把课桌的抽屉拉出来抖了抖，粉笔灰和橡皮屑落下来，被风一吹就散。宋阿婆家的小卖部门口围满了人，雨后的石板有点滑，脚步声闷闷的。阿婆用蒲扇赶着蚊子，给我们一人塞了一颗海盐糖，糖纸有点潮，被风吹得发软。咸味先化在舌尖，随后才有淡淡的甜漫上来，混着雨后的潮气。

我把糖在手心转了两圈，没急着吃，揣进口袋暖着。热水在杯子里晃，热气熏得脸有点红。

“去海边走走吗。”她小声说，“最后一次，以高二的名义。”

南雾县靠雾海，浪不大，风却足。我们几个顺着堤岸往前走，鞋里灌进细沙。天空是乳白色的，雾气贴着海面爬，远处的船影只剩一个模糊的轮廓。

林小满捡了块扁石头打水漂，石头在水面跳了两下，溅起细碎的水花，随后就沉了。她笑起来，鞋里进了沙子，走路有点晃。陈默坐在防波石上，把旧磁带揣在兜里，磁带壳被他用袖口擦了擦，齿轮轻轻转了一下，说里面录的是这个夏天的风声和蝉鸣，留到以后听。海风把他的头发吹得乱乱的。

顾远和秦浩在比谁能把海盐糖含得更久，赵晴和何晓蹲在沙滩上捡贝壳，笑声被风扯得很长。

我和江苒落在最后，海风把她的裙摆吹得轻轻翻。她抱着那个玻璃罐，走了很久才停下来，把罐子举到眼前晃了晃，星星在玻璃里轻碰，沙沙响。细沙钻进鞋里，凉凉硌脚，我跺了跺，沙子又落回滩上。

“你知道里面有多少颗吗。”她问，声音被风吹得有点散，眼里映着乳白的天光。

我点头。昨夜我一颗一颗数过，数到最后手指都有点抖。那是她从开学第一场雨开始叠的，难过叠一颗，开心叠一颗，想我又不好意思说的时候，也叠一颗。

“二十七颗。”我说，“一颗不少。”

她把罐子抱紧，脸颊贴着冰凉的玻璃，眼睛弯起来。

“那你知道我许了什么愿吗。”

海风把她的发丝吹到我手背上，痒痒的。我摇头，说你上次说过，愿望要藏好。

她嗯了一声，把一颗海盐糖塞进我掌心，糖纸已经被手心焐得发软。

“我还是不告诉你。”她说，“说出来就不灵了。”

我捏着那颗糖，纸星星的棱角仿佛透过玻璃硌着我的心口。我想问她愿望里有没有我，有没有高三，有没有雾散之后的地方。可话到嘴边，又咽了回去。这个年纪的喜欢，好像说重了会碎，说轻了会散，不如先放在罐子里。

“好。”我说，“那我等它自己实现。”

她笑了，笑里有海水的咸。身后林小满在大喊，让我们快点，落潮了，再不走要被困在滩涂上。

回学校的路上，雨又开始落。校门口的布告栏前围了一圈人，白纸上写着新学年的安排，高三两个字被放在最上面，墨迹很重，压得纸都微微卷边。叶老师站在廊下看着我们，没催促，只招了招手。

“回来就好。”她说，“新的教室已经在通气了，钥匙明天交。”

宋阿婆在对街喊我们过去躲雨，塞给我们热乎乎的姜汤。热气熏着眼睛，江苒捧着杯子，小口喝着，忽然抬头看我。

“沈聿。”

“嗯。”

“高三会很苦吧。”

我看着她杯沿上的雾气，看着罐子里满满的星星在灯下闪着微光。我把那颗没舍得吃的海盐糖放进兜里，和旧磁带的边角贴在一起。

“会吧。”我说，“但我们都在。”我把糖纸捻了捻，甜香混着咸香留在指尖，风把雨丝吹斜，落在手背凉凉的。

她没再说话，只是把玻璃罐往我怀里推了推，让我抱着。罐子沉甸甸的，玻璃被她焐得温热，星星的棱角隔着玻璃硌着胸口。雨点敲在棚顶上，密集起来，像倒计时之前的呼吸，细细的，急急的。我们站在布告栏前，看着高三两个字，墨迹在雨气里有点洇，心跳也跟着快起来。

我抱紧罐子，忽然很清楚地意识到，高二真的结束了。那些没说出口的愿望，那些叠进星星里的心事，都被完整地封存在这个潮湿的黄昏，像潮汐退后留下的贝壳，轻轻留在沙上。而明天，那扇写着高三的门，就要开了，门后的风会更急，卷子会更厚，日子会更紧。

江苒把手伸进口袋，摸出一颗橘子，分成两半，一半塞进我手心，橘瓣凉凉的，甜香清清的。我含进嘴里，汁水在舌尖爆开，混着海盐糖的余甜。

江苒用指尖在我掌心写了一个字，很轻，像怕被雨听见，指腹凉凉滑过，痒痒的。我握着她的手，雨水在我们指尖连成细线。

我没看清。风太大了，雨点砸在掌心，把字痕都吹散了。

“你写了什么。”我问，声音被风扯了一下。

她眨眨眼，把手指竖在唇边，眼睛弯起来。她轻声说，“高三告诉你。”顿了顿，又补一句，二十七颗集满了，愿望还不说，等潮水再涨一次。

我点头，把罐子抱得更紧，星星在玻璃里晃，二十七颗，一颗不少，都在。雨越下越密，前路像被雾盖住一点，但罐子在怀里很沉，很实。
