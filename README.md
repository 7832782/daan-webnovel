## 体量（准确统计）

| 口径 | 数值 |
|---|---|
| 含标点总字数（去空白） | 304,600 |
| 纯汉字数 | 260,617 |
| 平均每章（含标点） | 约 2,538 |

按出版口径（含标点）约 30.5 万字，纯汉字约 26 万，已远超过长篇线（评奖口径为版面字数 13 万）。

> 早前口头报过的「43万字」是统计方式出错导致的虚高数字（用 PowerShell 读 UTF-8 中文时按默认编码解析，汉字被拆成更多字符），非实际内容，已作废。以本表为准。
